# GEO – Fenced Emergency Alert and Safety Assistance System for Women

## Project Overview

GEO is a geo-fenced emergency alert and safety assistance system designed to provide timely assistance to women when they enter or encounter potentially unsafe situations.

The system combines a mobile application, IoT-based sensing, GPS location tracking, and a backend server to support emergency detection, location monitoring, and alert communication.

## Objectives

- Provide emergency assistance through a mobile application.
- Use GPS and geo-fencing to identify safety-sensitive locations.
- Monitor relevant sensor information through an IoT device.
- Enable emergency alerts and location sharing.
- Provide a backend service for communication and data management.
- Provide a guardian interface for monitoring and assistance.

## System Components

### 1. Mobile Application

The mobile application provides the user interface for the safety system and supports emergency assistance and location-related functionality.

### 2. IoT Module

The IoT component uses an ESP32-based system for sensor integration and communication.

### 3. Backend

The backend provides server-side functionality for handling application requests, data, and communication between system components.

### 4. Guardian Interface

The guardian component provides an interface through which emergency information and relevant user details can be monitored.

### 5. Documentation

The documentation folder contains project architecture, setup instructions, and information required to run and understand the system.
